# nz-data-engineer-journey
This repository demonstrates hands-on projects in data engineering, covering batch and streaming data pipelines, cloud-based architectures, and production-level coding practices.

The focus includes:

- Python-based data processing
- Pandas and PySpark
- Data warehouse modeling
- AWS cloud fundamentals
- Orchestration (Airflow)
- End-to-end ETL project development

The goal is to build production-style data pipelines and maintain a portfolio of practical projects.
